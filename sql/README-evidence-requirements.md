# شواهد مطلوبة واعتماد المدير — دليل التطبيق

## الفرع
`feature/evidence-requirements-approval`

## قبل التطبيق على قاعدة البيانات
1. شغّل `sql/phase_evidence_requirements_precheck.sql` وسجّل أعداد البرامج/المؤشرات/الشواهد.
2. أنشئ نسخة احتياطية للجداول المتأثرة (الأوامر داخل ملف الـ precheck).
3. طبّق `sql/phase_evidence_requirements_review.sql` مرة واحدة من Supabase SQL Editor.
4. أعد تشغيل نفس استعلامات العدّ — يجب ألا ينقص أي عدد.

## سلوك الترحيل
- كل شاهد قديم مرتبط بمؤشر يحصل على صف في `evidence_requirements` باسم من `title` أو `file_name` أو «شاهد سابق».
- `is_approved = false` دائماً عند الترحيل (قيد المراجعة)، إلا إذا وُجدت لاحقاً آلية اعتماد صريحة.
- لا حذف لملفات Storage ولا تغيير لمساراتها.

## الأدوار
| الدور | مفتاح DB | الشواهد المطلوبة | الإرفاق | الاعتماد ✓ |
|------|----------|------------------|--------|------------|
| مدير | `admin` | إدارة كاملة | نعم | نعم |
| وكيل/ة | `vice` | إضافة/تعديل أسماء | نعم | لا |
| معلم/ة | `teacher` | عرض فقط | نعم | لا |

## الواجهة
داخل تفاصيل البرنامج → كل مؤشر → قسم «الشواهد المطلوبة».
