لا شيء هنا يُطبَّق تلقائيًا. كل خطوة يدوية، وبعد مراجعة نتيجة الخطوة السابقة.

> ⚠️ **دمج الـ PR في `main` = نشر الواجهة** (GitHub Pages).
> لا تدمج قبل تطبيق الخطوة 1 على قاعدة الإنتاج.

## النطاق
- جدول `public.tasks` وواجهة قسم المهام فقط.
- لا يتغير شيء في البرامج أو المؤشرات أو شواهدها أو Storage أو `profiles` أو الدخول أو أي قسم آخر.
- سياسات `tasks` الحالية للقائدة والوكيلة (`tasks_select` / `tasks_insert` / `tasks_update` / `tasks_delete`) تبقى كما هي. يُضاف فقط ما يلزم لحساب المعلمات المشترك.
- المهام الحالية وبياناتها تبقى كما هي: الاسم، «المسؤولة»، تاريخ الاستحقاق، الملاحظات وما فيها من روابط، `created_by`.

## 0) نسخة احتياطية + تقرير القراءة فقط
1. لوحة Supabase → Database → Backups: تأكد من وجود نسخة حديثة.
2. SQL Editor → الصق `sql/phase_task_schedule_precheck.sql` → Run → انسخ عمود `report` إلى الـ PR. التقرير أعداد فقط، بلا أسماء أو بريد أو روابط.

**توقّف** إن كان `missing_helpers` أو `new_columns_already_present` غير فارغ.

## 1) توسيع جدول المهام
`sql/phase_task_schedule_evidence_review.sql`:
- يضيف `start_at` و`end_at` (timestamptz، تُعرض بتوقيت جهاز المستخدم).
- يضيف **رابط Google Drive واحدًا** لكل مهمة (`evidence_drive_url`)، مع حقول الاعتماد (`evidence_approved` ومن اعتمد ومتى) ومن أرفق الرابط ومتى.
- لا يوجد اسم شاهد، ولا رفع ملفات، ولا روابط متعددة.
- قيود: النهاية بعد البداية، والأوقات معًا أو لا شيء، والرابط على `drive.google.com` أو `docs.google.com` فقط بلا مسافات.
- المشغّل:
  - حساب المعلمات يغيّر الرابط فقط، ولا يستطيع مسحه.
  - الاعتماد للقائدة فقط.
  - بعد الاعتماد يُقفل الرابط حتى تلغي القائدة الاعتماد.
- سياستان لحساب المعلمات المشترك:
  - يرى مهام السنة النشطة.
  - يضيف الرابط أو يستبدله لمهمة في السنة النشطة لم يُعتمد رابطها.
- **الرجوع:** كتلة معلّقة في آخر الملف تحذف الإضافات فقط ولا تحذف أي مهمة. لكنها تُفقد الأوقات والروابط المُدخلة بعد التطبيق، فلا تُستخدم إلا عند الضرورة.

**الحساب المشترك:** «المسؤولة» معلومة تنظيمية للعرض فقط. من أرفق الرابط يُسجَّل بمعرّف الحساب المشترك، دون نسبته إلى معلمة بعينها.

## 2) نشر الواجهة
- ادمج الـ PR. رقم الإصدار في `index.html` هو `?v=20260929-tasks`.
- **التحقق:** افتح المنصة وأعد التحميل (Ctrl+F5). يجب أن تظهر «بداية المهمة» و«نهاية المهمة» وحقل رابط Drive واحد.
- **اختبار يدوي:**
  - الوكيلة: تضيف مهمة بأوقات و«المسؤولة».
  - حساب المعلمات: يرى المهمة ويضغط «📎 إرفاق شاهد» ويلصق رابط Drive، ثم يستبدله.
  - القائدة: تعتمد الرابط.
  - حساب المعلمات: يختفي زر التعديل.
- **الرجوع:** `git revert` لـ merge commit ثم push. الواجهة الحالية تعمل مع مخطط الخطوة 1.

## 3) فرض الأوقات عند الإضافة
`sql/phase_task_schedule_enforce_review.sql`، بعد التأكد من أن الجميع على الواجهة الجديدة. الاستعلام في رأس الملف يعدّ المهام بلا أوقات المضافة خلال آخر 24 ساعة، والمتوقع 0.

**الرجوع:** كتلة معلّقة تحذف المشغّل فقط، فورًا ودون أن تمس البيانات.
